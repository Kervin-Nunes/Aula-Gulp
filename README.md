# Aula Gulp — Automação de Tarefas ⚡

Repositório de estudo sobre o uso do **Gulp** como task runner no desenvolvimento front-end. O projeto demonstra a configuração de tarefas automatizadas com foco em produtividade e otimização do fluxo de trabalho.

## 🛠 Tecnologias utilizadas

- JavaScript
- Gulp (task runner)
- SCSS (pré-processador CSS)

## ⚡ Tarefas automatizadas com Gulp

- Compilação de **SCSS** → CSS
- Minificação de arquivos
- Watch para recompilação automática

## 🚀 Como rodar

```bash
npm install
npx gulp
```

## 💡 Objetivo

Comparar e compreender as diferenças entre Gulp e Grunt como task runners, entendendo a abordagem baseada em streams do Gulp para pipelines de build front-end.
